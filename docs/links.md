# 链接与转载指南

本文说明在 `src/posts/*.md` 写作时如何使用链接、站内互链和转载标注。相关底层行为（已实测确认）：

- Markdown 渲染的链接是普通 `<a>`，**默认不带 `target="_blank"`**，即在当前标签页打开
- 正文里点链接会触发 **SPA 整页刷新**（router 有预加载路径则无感，其余场景浏览器会白屏一瞬），属于正常现象
- 解析器开着 `linkify: true`，正文里的裸 URL 会自动变成可点链接（`fuzzyLink` 已关，不会误伤普通短文本）

## 一、外部链接写法

### 默认写法（当前标签页打开）

```markdown
参考 [Vite 官方文档](https://cn.vitejs.dev/)。
```

裸 URL 也会自动生效：

```markdown
官方文档：https://cn.vitejs.dev/
```

### 需要在新标签页打开时

用行内 HTML（站内 md 支持行内 HTML）：

```markdown
<a href="https://example.com" target="_blank" rel="noopener noreferrer">外部网站</a>
```

约定：指向**站外**且用户大概率不希望离开文章的链接（如文档、参考原文地址）建议用新标签页；`rel="noopener noreferrer"` 一定要带（安全 + 无 referrer 泄漏）。

## 二、站内文章互链

- 路径写**站点绝对路径**，且必须用文章的 slug（md 文件名），不是相对文件路径：

```markdown
前文提到过 [Vue3 + Vite 搭博客](/blog/vue3-vite-blog) 的方案。
```

- slug 写错浏览器会显示「文章不存在」页（有返回入口，不会白屏），发布前自查一遍。

## 三、转载其它网页的文章

### 推荐方式：frontmatter `source` 字段

```yaml
---
title: 原文标题
date: 2026-11-03
tags: [转载]
source: https://原文链接
---
```

文章页会在头部自动渲染标注条：「本文转载自 <原文链接>，版权归原作者所有」。原创文章**不要写** `source`（不写就不渲染标注条）。要筛出全站转载文，看列表页 `转载` 标签即可。

### 不用 source 字段的方式（零代码）

复制原文为 md，正文开头用引用块手写出处：

```markdown
> 本文转载自 [原文标题](https://原文链接)，作者：某某，遵循 CC BY 4.0。以下为正文。
```

适合需要自定义说明文字（如授权方式、译者注）的场景。

### 版权提醒

1. 转载前确认原文许可：明确允许转载（CC BY / CC BY-SA 等）、或已获得作者授权的才转。
2. 保留作者署名与原文链接；`source` 字段方式已自动保留链接，署名可写在正文开头引用块里。
3. 不转载「版权所有、禁止转载」的内容——这类写「阅读原文」式的外链推荐即可（用上面的外部链接写法）。

## 四、非写作层面的链接（区分开）

这些不属于写作层面，改的话要动数据层代码：

| 想改什么 | 改哪里 |
| --- | --- |
| 首页 hero 区的社交/邮箱链接 | `src/site.ts` 的 `links` |
| 关于页联系方式列表 | `src/site.ts` 的 `links`（两处共用同一份数据） |
| 任何页面组件里的链接 | Vue 模板里用 `RouterLink`，不要用裸 `<a>`（会整页刷新） |
